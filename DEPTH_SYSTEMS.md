# MetaHuman Legacy — Depth Director

This production pass deepens the existing life/choice loop without adding a second game.

Implemented systems:

1. Long-term choice memory and callbacks.
2. Deferred consequences that can return years later.
3. Persistent promises with kept/broken states.
4. Emergent personal code inferred from repeated decisions.
5. Multi-axis relationships: trust, affection, fear, admiration, grudge, dependence.
6. Autonomous NPC pulses between player decisions.
7. Rival/Nemesis adaptation to repeated approaches.
8. Antagonist origins created by collateral, humiliation or exposure.
9. Independent background pressure clocks.
10. Multiple concurrent pressures surfaced in story context.
11. Mixed/interesting failures rather than binary reset.
12. High-stakes trade-offs added to major choices.
13. Imperfect information and reliability context.
14. Skill-gated contextual choices from annual actions.
15. Past/promise-gated contextual choices.
16. Separate identity suspicion for family, rival, media and government.
17. Cover-story/alibi options when earned by skills.
18. Deterministic witness/camera/official-presence context.
19. Evolving media framing.
20. Evolving legal status.
21. Persistent collateral index.
22. Named persistent injuries.
23. Power evolution based on actual use patterns.
24. Signature techniques earned through repeated use.
25. Evolving power strain/cost pressure.
26. Domicile/refuge/HQ stage derived from career.
27. District sentiment and landmark memory.
28. Seeded long-term mystery progression.
29. Career-specific Legacy title, score bonus and summary hooks.
30. Anti-repetition/story-director context using recent categories, memories, clocks and underused consequences.

Persistence stays inside Campaign V4 flags, so no destructive save migration is required. The first ten formative decisions still exclusively determine the hidden power vectors through the original GameRules/PowerResolver path.
