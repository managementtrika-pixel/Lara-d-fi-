# Audit 2.6 — défauts systémiques

Cette passe considère comme défectueux tout système présent dans le code mais non causal, non atteignable, purement décoratif ou incohérent avec l'interface réellement jouée.

Défauts déjà confirmés et corrigés / en correction :
- présence de PNJ sans lien causal avec la scène ;
- double mutation concurrente des relations ;
- retraite à 68 ans auparavant inaccessible à cause d'une fin naturelle à 65 ans ;
- classification Legacy incohérente avec la nouvelle durée de vie ;
- architectures de pouvoirs déduites de mots-clés trop fragiles ;
- faiblesses de pouvoirs principalement textuelles au lieu de mécaniques ;
- opportunités ignorées sans coût systémique réel ;
- métriques de ville trop brutes dans l'UI principale ;
- fallback vers l'ancien shell de carrière encore atteignable ;
- écran Liens encore trop consultatif ;
- couverture UI/instrumentation trop faible pour détecter les régressions qualitatives.

Ce document est mis à jour pendant la passe d'audit et ne constitue pas une déclaration de fin de chantier.
